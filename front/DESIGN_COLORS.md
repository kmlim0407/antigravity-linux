# SMOOKTH 디자인 컬러 룰 (3색 사용)

사이트 전반에서 **3가지 메인 색**만 사용합니다.

---

## 1. Primary (메인)
- **Slate 800** `#1e293b` / `slate-800`
- 용도: 본문 텍스트, 제목, 강조 문구

## 2. Accent (강조)
- **Blue 600** `#2563eb` / `blue-600`
- 용도: 링크, 버튼 호버, CTA, 로고 포인트

## 3. Neutral (보조)
- **Slate 200** `#e2e8f0` / `slate-200`
- 용도: 테두리, 얕은 배경, 카드 구분선

---

### 보조 색상 (배경·그림자용)
- **White** – 카드, 패널 배경
- **Slate 100/50** – 연한 배경, 호버 시
- **Slate 900** – 버튼, 배지 등 필요한 곳에만

---

### 적용 예시
```
text-slate-800    → Primary (텍스트)
text-blue-600     → Accent (링크)
border-slate-200  → Neutral (테두리)
bg-white          → 카드 배경
```
